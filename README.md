# SigmaOS-onlyoffice-spreadsheet

> **SigmaOS ONLYOFFICE Spreadsheet Subsystem** — Tabular data processing, formula recalculation engine, charts, and XLSX interoperability.

Part of the [SigmaOS](https://github.com/AaryanSinghChauhan09/SigmaOS) ecosystem.

## Quickstart

```bash
cargo build --release
cargo test
```
